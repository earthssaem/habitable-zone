# 생명 가능 지대 탐구실 🪐

고등학교 지구과학 수업용 시뮬레이션 웹앱입니다. 학생이 **별의 광도를 직접 조절**하면서 생명 가능 지대가
멀어지고 넓어지는 모습을 관찰하고, 그 이유까지 스스로 설명할 수 있게 합니다.

> 왜 광도가 큰 별일수록 생명 가능 지대가 더 멀리 있고, 그 폭도 넓을까?

설치·빌드 없이 `index.html` 하나로 동작합니다(HTML·CSS·JS·인라인 SVG, 외부 CDN 없음).

## 사용 방법

- **바로 열기**: `index.html`을 브라우저에서 엽니다.
- **배포(Vercel)**: 저장소를 Vercel에 Import → Framework Preset `Other` → Deploy. 빌드 설정은 필요 없습니다.

## 화면 구성

상단 메뉴에서 단계를 자유롭게 오갈 수 있습니다(잠금·완료 조건 없음). 제목을 누르면 1단계로 돌아갑니다.

| 메뉴 | 내용 |
|---|---|
| **1 변화 관찰하기** (첫 화면) | 위쪽에 광도 슬라이더(태양의 0.25~9배, 기본 1배)와 빠른 선택 `0.25배 / 1배 / 4배 / 9배`. 바로 아래 0~6 AU **고정 선형 거리축** 위에 태양의 생명 가능 지대(회청색, 고정)와 지금 별의 띠를 함께 그립니다. 지금 별의 띠는 받는 에너지에 따라 주황(많음)→초록(생명 가능 지대)→파랑(적음)으로 바뀌고, 두 경계선이 각각 움직이며 폭은 양방향 화살표로 표시됩니다. **변화 전과 비교**: `지금 광도를 기준으로 저장`을 누르면 그 위치가 점선 윤곽으로 남고(`비교 해제`로 지움), 아래 수치 카드(안쪽 경계·바깥쪽 경계·폭)에 기준(없으면 태양) 대비 배수가 작게 나옵니다 |
| **2 원리 알아보기** | ① 광도와 거리: 별빛 점이 사각뿔로 퍼지는 장면 4개(광도 1배·1 AU → 광도 4배·1 AU → 광도 4배·2 AU → 광도 9배·3 AU)와 직접 해 보기(광도 1/4/9배 × 거리 1/2/3 AU). ② 폭이 넓어지는 이유: 태양과 광도 4배(또는 0.25·9배) 별을 같은 축척으로 비교해 두 경계가 모두 √(광도)배 멀어지고 폭도 같은 배수가 됨을 보여 줍니다. ② 두 번째 장면은 4단계(광도 4배 → 같은 에너지를 받는 거리 2배 → 두 경계 모두 2배 → 폭 2배)로 설명하고, 마지막 장면은 `광도 4배 → 경계 거리 2배 → 생명 가능 지대 폭 2배` 흐름과 핵심 관계 `d ∝ √L`, `W ∝ √L`(두 경계의 에너지 기준을 고정한 모형에서 성립)을 크게 보여 줍니다. 그림 아래에 수치 비교 표와 반올림 안내가 있고, 자세한 식(S = L/d², d = √(L/S), 두 경계, 폭 W = (1/√0.35 − 1/√1.1)√L ≈ 0.737√L)은 `계산 과정 보기`를 눌러야 펼쳐집니다. 수식은 외부 라이브러리 없이 HTML·CSS로 그립니다 |
| **3 적용하기** | 비교(1) · 판단(3) · 예측(3) · 핵심 퀴즈(3), 모두 10문제. 그림이 있는 문제는 답을 고르면 생명 가능 지대가 나타납니다 |
| **＋ 심화 탐구** | 도전! 생명 가능 지대 찾기(질량이 다른 별에서 행성을 끌어 경계 기록, ±5% 판정, 선생님 도구) · 에너지–거리 그래프 · 질량–거리 그림(선형/로그 축) · 모형의 한계 |

### 한 화면 맞춤

태블릿(가로·세로)·전자칠판·PC처럼 폭 700px·높이 540px 이상인 화면에서는 페이지를 스크롤하지 않고 한 화면에 모두 들어옵니다.
본문이 화면 높이를 꽉 채우고, 그림은 비율을 지키며 그 안에서 커지거나 줄어듭니다. 설명이 긴 패널만 패널 안에서 스크롤됩니다. 폰에서는 평소처럼 위아래로 스크롤합니다.
전자칠판처럼 큰 화면(폭 1600px·높이 950px 이상)에서는 글자와 버튼이 더 커져 멀리서도 잘 보입니다.
세로로 긴 태블릿에서는 그림 속 글자도 폰처럼 크게 그려 읽기 쉽게 합니다.

### 디자인

밝은 청회색 배경 위에 흰 카드를 놓은 수업용 화면입니다. 우주 느낌은 파란 헤더에만 은은하게 남겼습니다.
색은 정보 구분에만 씁니다: 파랑 = 기본 강조(선택·주요 버튼·슬라이더), 초록 = 생명 가능 지대, 연한 주황 = 너무 뜨거움, 연한 파랑 = 너무 차가움.

### 조작

- 광도 슬라이더: 끌기(마우스·터치), 키보드 ←/→(작게), PageUp/PageDown(크게), Home/End. 0.25·1·4·9배 근처에서는 그 값에 딱 맞춰집니다.
- 슬라이더의 눈금은 광도의 로그 눈금이라 0.25·1·4·9배가 고르게 놓입니다. 거리축은 바뀌지 않습니다.
- 빛 번짐(별 주변과 띠로 퍼지는 빛)은 광도만 나타냅니다. 광도만으로는 별의 실제 크기·색·온도를 정할 수 없어서 별의 크기와 색은 바꾸지 않습니다.
- 띠의 색은 행성이 받는 에너지의 많고 적음을 구분할 뿐, 행성의 실제 온도를 나타내지 않습니다.

## 물리 모형

`index.html`의 `<script>` 맨 위 상수만 바꾸면 계산과 설명 문구가 함께 바뀝니다.

```js
const HZ_INNER_S = 1.1;   // 안쪽 경계에서 받는 에너지(지구 = 1)
const HZ_OUTER_S = 0.35;  // 바깥쪽 경계에서 받는 에너지(지구 = 1)
const MASS_LUMINOSITY_POWER = 3.5;   // 심화 활동(질량이 다른 별)에서만 사용
```

- 받는 에너지 `S = L / d²` (L: 광도, 태양 = 1 · d: 거리, AU)
- 안쪽 경계 `√(L / 1.1)`, 바깥쪽 경계 `√(L / 0.35)`, 폭 = 바깥쪽 − 안쪽
- 계산은 반올림 전 값으로 하고, 표시할 때만 소수 둘째 자리로 반올림합니다.

| 광도 | 안쪽 경계 | 바깥쪽 경계 | 폭 |
|---|---|---|---|
| 1배 | 0.95 AU | 1.69 AU | 0.74 AU |
| 4배 | 1.91 AU | 3.38 AU | 1.47 AU |
| 9배 | 2.86 AU | 5.07 AU | 2.21 AU |

페이지를 열 때 `runSelfCheck()`가 위 표(그리고 심화 활동의 질량별 표)를 계산값과 비교해 콘솔에 결과를 출력합니다.

### 모형의 한계 (앱의 `심화 탐구 → 모형의 한계`)

받는 복사 에너지에 일정한 경계값을 적용한 단순화된 교육용 모형입니다. 실제 생명 가능 지대는 별의 스펙트럼과
행성 대기 조건 등에 따라 달라지며, 생명 가능 지대 안에 있다고 해서 생명체가 있다는 보장은 없습니다.

## 개인정보

이름·학번 등 어떤 정보도 묻지 않습니다. 쿠키·localStorage·서버 전송·분석 도구를 쓰지 않으며,
슬라이더 값·문제 답·도전 기록은 페이지 변수에만 있어 새로고침하면 사라집니다.
