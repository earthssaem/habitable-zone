# 생명 가능 지대 탐구실 🪐

고등학교 지구과학 수업용 시뮬레이션 웹앱입니다. 학생이 별마다 생명 가능 지대의 경계를 직접 찾으면서
**왜 광도가 큰 별일수록 생명 가능 지대가 멀고 넓은지** 설명할 수 있게 합니다.

```text
별의 질량 → 광도 → 거리별 받는 복사 에너지 → 생명 가능 지대의 거리와 폭
```

설치·빌드 없이 `index.html` 하나로 동작합니다(HTML·CSS·JS·인라인 SVG, 외부 CDN 없음).

## 사용 방법

- **바로 열기**: `index.html`을 브라우저에서 엽니다.
- **배포(Vercel)**: 이 저장소를 Vercel에 Import → Framework Preset `Other` → 그대로 Deploy. 빌드 설정은 필요 없습니다.

## 단계

| 단계 | 내용 |
|---|---|
| 1. 별빛의 세기 | 거리 1·2·3 AU에서 빛이 닿는 면이 1·4·9칸, 한 칸의 에너지가 1·1/4·1/9 |
| 2. 경계 찾기 | 행성을 끌어(또는 ±0.01 AU 버튼) 받는 에너지 게이지를 보며 안쪽·바깥쪽 경계를 기록. 정답 ±5% 안이면 인정, 아니면 방향만 안내. 0~8 AU 같은 축척 비교 그림 |
| 3. 왜 넓어질까 | 받는 에너지–거리 곡선과 경계 기준 점선, 바깥쪽 ÷ 안쪽 비율 예측 |
| 4. 교과서 그림 읽기 | 질량 × 거리(0.1~40 AU) 그림, 선형/로그 축 전환 애니메이션, 태양계 행성 |
| 5. 핵심 퀴즈 | 6문제, 바로 해설 |

**학생 탐구**(기본): 측정 전에는 경계 띠가 숨겨지고, 네 별을 모두 찾아야 3단계가 열립니다.
**교사 시연**: 경계 띠 켜기/끄기, `모두 채우기`, `d = √(L/S)` 표시, 단계 자유 이동.

## 물리 모형

`index.html`의 `<script>` 맨 위 상수만 바꾸면 계산과 설명 문구가 함께 바뀝니다.

```js
const HZ_INNER_S = 1.1;   // 안쪽 경계에서 받는 에너지(지구 = 1)
const HZ_OUTER_S = 0.35;  // 바깥쪽 경계에서 받는 에너지(지구 = 1)
const MASS_LUMINOSITY_POWER = 3.5;
```

`L = M^3.5`, `S = L / d²`, `d = √(L / S)`

| 별의 질량 | 광도 | 안쪽 경계 (AU) | 바깥쪽 경계 (AU) | 폭 (AU) | 바깥쪽 ÷ 안쪽 |
|---|---|---|---|---|---|
| 0.5 | 0.088 | 0.28 | 0.50 | 0.22 | 1.77 |
| 1 | 1.00 | 0.95 | 1.69 | 0.74 | 1.77 |
| 1.5 | 4.13 | 1.94 | 3.44 | 1.50 | 1.77 |
| 2 | 11.31 | 3.21 | 5.69 | 2.48 | 1.77 |

페이지를 열 때 `runSelfCheck()`가 위 표와 로그축 띠 폭(0.249)을 계산값과 비교해 콘솔에 결과를 출력합니다.
